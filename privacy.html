Privacy policy: KnotLogic Drive — rclone

Last updated: 26 September 2026.

This personal OAuth application is maintained by the owner of KnotLogic for access to the owner's own Google Drive accounts through rclone on Ubuntu.

Access and purpose

With the account owner's consent, rclone accesses Google Drive file names, folder structure, metadata, and file contents. Its Drive permission allows reading, creating, modifying, and deleting files. These capabilities support browsing and managing the owner's files through local folders and explicitly requested file operations.

Storage and protection

OAuth credentials and tokens are stored in the owner's local rclone configuration with filesystem access restricted to that operating-system user. Downloaded or edited files may be cached on the same computer. Communication with Google uses HTTPS. This website does not receive Drive files or OAuth tokens.

Use and sharing

Drive data is used to provide the described file-access features. This application does not sell Drive data or use it for advertising. Local applications or assistants may access the mounted folders when the owner directs them to do so; sending content to another service requires the owner's authorization and is subject to that service's terms. The application does not provide public access to the owner's files.

Retention and control

The owner controls downloaded copies, caches, and the local configuration. Revoking access in Google Account connections stops future authorized API access; it does not erase previously downloaded files or local caches. Those can be removed separately by the owner. Deleting files through a mounted folder changes the corresponding cloud files according to rclone's configured behavior.

Google API data policy

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

The maintainer is identified by the KnotLogic GitHub account. The owner can also use the support contact shown on the Google consent screen. Do not post private files, passwords, or tokens in public issue trackers.
